# GPT-3 Landing Page (React + Vite)

## التشغيل
```bash
npm install
npm run dev      # تطوير على http://localhost:5173
npm run build    # نسخة الإنتاج في dist/
npm run preview  # معاينة نسخة الإنتاج
```

## الهيكل
- `src/containers/` الأقسام السبعة: Header, Brand, WhatGPT3, Features, Possibility, CTA, Blog, Footer
- `src/components/` Navbar, Feature, Article, AvatarStack
- `src/data.js` كل النصوص والبيانات
- `src/index.css` كل الأنماط (متجاوبة: ديسكتوب / تابلت / موبايل)
- `src/assets/` الصور بعد الضغط (WebP) واللوجوهات
